## 命名规则

`UI<两位编号>-<页面名>.png`

- 同一页面有多个变体时,加后缀 `2` / `3`(如 `UI02-主屏幕.png` / `UI02-主屏幕2.png`)
- 编号顺序对应主流程,不轻易改动
