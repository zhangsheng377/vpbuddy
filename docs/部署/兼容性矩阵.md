# 兼容性矩阵

> 哪些版本组合能用,哪些不能用,2026-06-21 验证。

## Python 依赖

| 包 | 最低版本 | 最高版本 | 验证版本 | 关键说明 |
|---|---|---|---|---|
| python | 3.10 | 3.12 | 3.11.14 | 3.13+ 未测,某些包可能没 wheel |
| torch | 2.5 | 3.0 | 2.5.1+cu121 | **必须 GPU 版** (pip install torch 装的是 CPU 版,要 `pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121`) |
| torchaudio | 2.5 | 3.0 | 2.5.1 | 跟 torch 同版本 |
| pyannote-audio | 3.3 | 4.0 | 3.3.2 | **3.3.2 + HF 1.20 有兼容 bug,需 monkeypatch**(见踩坑记录 §1) |
| pyannote-core | 6.0 | 7.0 | 6.0.1 | pyannote-audio 自动拉 |
| huggingface_hub | 1.20 | 2.0 | 1.20.1 | **1.0- 是旧 API,与 pyannote 3.3 不兼容** |
| funasr | 1.1.9 | 2.0 | 1.3.11 | 含 SenseVoice/Paraformer/VAD |
| modelscope | 1.20 | 2.0 | 1.20.1 | 国内模型镜像 |
| faster-whisper | 1.0 | 2.0 | 1.0.3 | ctranslate2 加速,可不用(VPBuddy 用 SenseVoice) |
| ctranslate2 | 4.8 | 5.0 | 4.8.0 | faster-whisper 依赖 |
| sqlite-vec | 0.1 | 0.2 | 0.1.6 | 知识库向量索引 |
| numpy | 2.0 | 3.0 | 2.0+ | ⚠️ pyannote 3.3 还不完全兼容 numpy 2.0,实测可用但有 warning |

## 已知不兼容组合

| 组合 | 现象 | 解决方案 |
|---|---|---|
| pyannote-audio 3.3.2 + HF < 1.0 | 用 `use_auth_token` 但新版不支持 | 升级 HF 到 1.20+ |
| pyannote-audio 3.3.2 + HF 1.20+ | HF 移除了 `use_auth_token`,pyannote 没适配 | monkeypatch(踩坑记录 §1) |
| pyannote-audio 3.3.2 + numpy 1.x | 可能 | 升级 numpy 到 2.0 |
| SenseVoice 无 VAD/punc/spk | 只输出 1 个 segment | 加 vad/punc/spk model(踩坑记录 §5) |
| sentence_timestamp=True + punc | KeyError | 不传(踩坑记录 §6) |

## 升级策略

**遇到新 bug 时的诊断顺序**:

1. `python -c "import torch; print(torch.__version__, torch.cuda.is_available())"` → 确认 GPU torch
2. `pip list | grep -E "pyannote|funasr|modelscope|huggingface"` → 确认版本组合在表中
3. 看 [`踩坑记录.md`](./踩坑记录.md) 是否有类似现象
4. 都没找到?开新条目,记下**版本组合 + 现象 + 解决方案**
