# 系统设计 (System Design)

本目录用于存放 VPBuddy 的系统设计文档,包括但不限于:

- 总体架构设计
- 模块详细设计(会议接入层 / 会议理解 / Agent 系统 / 交付物生成 / 指令控制 / 知识库)
- 数据模型与接口设计
- 关键流程(会议接入、需求结构化、Sub-agent 协同、交付物演化等)
- 非功能性设计(性能、可用性、安全、可扩展性)

## 文件命名

`<模块或主题>.md`,例如:

- `总体架构.md`
- `会议接入层设计.md`
- `Sub-agent系统设计.md`
- `知识库系统设计.md`

## 文档模板

每篇文档顶部建议包含元信息:

```markdown
# <标题>

- **状态**: 草稿 / 评审中 / 已定稿
- **作者**: 
- **更新日期**: YYYY-MM-DD
- **关联**: [产品说明书](../product-spec/VPBuddy_产品说明书.md) · [相关 ADR](../../decisions/)
```
