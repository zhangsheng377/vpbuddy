## 1. 后台任务队列 (#5)

### 现状问题

- ThreadPoolExecutor per-chunk 创建，长会议无限堆积
- 相邻 chunk 重复触发文档生成，无去重
- daemon 线程超时后 agent 仍可能继续写文件
- 同一会议多个过期 doc generation 并发写

### 方案

**per-meeting bounded queue**:
```python
class DocTaskManager:
    per_meeting: dict[str, MeetingTaskQueue]
    global_executor: ThreadPoolExecutor(max_workers=4)

class MeetingTaskQueue:
    lock: threading.Lock
    pending_task: DocTask | None  # 只保留最新待处理任务 (debounce)
    current_generation_id: int
    last_processed_chunk: int
```

关键设计点：
- **Debounce**: 连续 chunk 只保留最新的 task，旧的自动丢弃
- **Generation ID**: 每次触发递增，写入前检查 ID 防止旧任务覆盖新结果
- **Cancellable timeout**: Future.result(timeout=) + generation_id 检查
- **状态**: queued / running / completed / timed_out / cancelled

### 文件位置
- 新建 `src/vpbuddy/task_manager.py`
- `ui_server.py` 中 _handle_stream_chunk 的 trigger 逻辑切到 task_manager

### 验收

- 长会议不会无限创建线程
- 同一 meeting 同一时间只有 1 个 doc generation 在跑
- 超时任务不会在超时后继续改写最终文档

## 2. 经验蒸馏 Phase 1 (#1)

### 数据模型

```python
class ExperienceItem(BaseModel):
    id: str
    kind: Literal["domain_fact", "product_pattern", "decision_rule",
                  "terminology", "failure_lesson", "user_preference"]
    text: str
    domain: str | None          # 领域 (如 "physics", "fintech")
    product_type: str | None    # 产品类型
    evidence: list[str]          # 来源证据 (state 原文引用)
    source_meeting_id: str
    confidence: float            # 0-1
    approved: bool               # 默认 False, 用户确认后才激活
    created_at: str
```

### 抽取触发点

1. **会议结束 / close meeting** (`/api/meetings/{id}/stream_stop`): 自动从 MeetingState 提取
2. **用户确认文档**: 从 batch_docs 输出中提取领域知识
3. 候选经验写入 `data/experiences/{meeting_id}.json`

### 检索注入

`batch_docs.md` 和 `sub_session_controller` 在生成文档前：
1. 读取 `data/experiences/*.json` 中所有 `approved=True` 的条目
2. 按 `domain` / `product_type` 匹配当前会议
3. 把匹配经验注入 prompt 上下文

### 文件位置
- 新建 `src/vpbuddy/experience.py` — ExperienceItem 模型 + extract 逻辑
- 新建 `src/vpbuddy/experience_store.py` — JSON 持久化 + 检索
- `ui_server.py` — stream_stop 时触发提取
- `prompts/batch_docs.md` — 检索注入 section

### 验收

- 会议结束后自动生成 `data/experiences/{meeting_id}.json`
- 后续会议 batch_docs 会引用已确认经验
- 未确认的经验不注入
