## 维护规则

1. **以 .docx 为准**。Markdown 是渲染副本,如有歧义以 .docx 内容为准。
2. **改 .docx 后必须同步 .md**。两者内容应保持一致,可以在 PR 中看到差异。
3. **版本变更**。每次重大版本变更:
   - 把当前主 docx 重命名为带版本号的备份(如 `VPBuddy_产品说明书_v1.1_2026-06-20.docx`)
   - 创建新版本主 docx
   - 重建 source/ 下对应的 zip 备份
4. **source/ 只读**。`source/*.zip` 是历史版本原始材料,不再修改,只作存档。
