## 版本历史

- **v1** (2026-06-20): 初版,11 章节
- **v1.1**: 去掉"实时"假设 → 后台持续累积
- **v1.2**: 强化"后台并行生成交付物"是核心价值
- **v1.3**: §九 知识库"约束 vs 检索"改为双模式
- **v1.4** (2026-06-20): 与架构 v1.5 对齐 — §九 强化"**展示模式不注入 system prompt,不阻塞 AI 继续做 demo**"

### v1.3 → v1.4 主要变更(2 处)

| # | 章节 | v1.3 原文 | v1.4 修改 |
| --- | --- | --- | --- |
| 1 | §九 | "知识库是统一的双模式系统(约束 + 检索),包含三类知识" | "知识库包含三类知识,采用**展示+检索**双模式;后台**实时提取并展示**,VP 可改但**不阻塞 AI 继续做 demo**;约束**不注入 system prompt**" |
| 2 | §九 作用 | "约束类(规则/SOP/规范)→ 注入 system prompt,LLM 必须遵守" | "**展示类**(`mode: constraint`)= 后台实时识别,展示在 Demo 上,VP 可看/改/问,**不强制确认,不阻塞 AI 继续做**;约束**不注入 system prompt**" |

## 维护规则

1. **以 .docx 为准**。Markdown 是渲染副本。
2. **改 .docx 后必须同步 .md**。
3. **版本变更**:把当前主 docx 重命名为带版本号的备份,创建新版本主 docx,重建 source/ 下对应的 zip 备份。
4. **source/ 只读**:历史版本原始材料存档。
