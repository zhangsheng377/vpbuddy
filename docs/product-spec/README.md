## 维护规则

1. **以 .docx 为准**。Markdown 是渲染副本,如有歧义以 .docx 内容为准。
2. **改 .docx 后必须同步 .md**。两者内容应保持一致。
3. **版本变更**:把当前主 docx 重命名为带版本号的备份,创建新版本主 docx,重建 source/ 下对应的 zip 备份。
4. **source/ 只读**:历史版本原始材料存档,不再修改。
