# 产品说明书 (Product Spec)

本目录存放 VPBuddy 的产品定位与原始需求文档。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `VPBuddy_产品说明书.docx` | 原始 Word 文档,便于编辑 |
| `VPBuddy_产品说明书.md` | Markdown 渲染副本,便于 GitHub 浏览与 diff |
| `source/0620.zip` | 2026-06-20 收到的原始材料压缩包备份(完整保留) |

## 维护规则

1. **以 .docx 为准**。Markdown 是渲染副本,如有歧义以 .docx 内容为准。
2. **改 .docx 后必须同步 .md**。两者内容应保持一致,可以在 PR 中看到差异。
3. **版本变更**。每次重大版本变更在文件名加日期后缀(如 `VPBuddy_产品说明书_v2_2026-07-15.docx`),旧版保留不删除。
4. **source/ 只读**。`source/0620.zip` 是 2026-06-20 收到的原始材料,不再修改,只作存档。

- **v1** (2026-06-20): 初版,11 章节,定义产品定位、五大系统、核心闭环。
