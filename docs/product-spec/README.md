## 版本历史

- **v1** (2026-06-20): 初版
- **v1.1**: 去掉"实时"假设
- **v1.2**: 后台并行生成交付物
- **v1.3**: §九 知识库"约束 vs 检索"改为双模式
- **v1.4**: §九 强化"展示模式不注入 system prompt,不阻塞 AI"
- **v1.5** (2026-06-20): 与架构 v1.6 对齐 — **范式转变**: §七 指令控制层 → **Steer 控制层**;§六/§十 强化"**VP 持续 steer(对持续过程)**,不是干预已就绪成果,没有『完成』概念"

### v1.4 → v1.5 主要变更(3 处)

| # | 章节 | v1.4 原文 | v1.5 修改 |
| --- | --- | --- | --- |
| 1 | §七 标题 | "七、指令控制层(Command Center)" | "七、Steer 控制层(Steer Center,v1.5 改名)" |
| 2 | §七 入口/支持/本质 | "VP与VPBuddy唯一交互入口 / 支持自然语言指令:... / 本质:会议操作系统的控制台" | "VP与VPBuddy唯一交互入口(v1.5 改为steer 入口) / VP 在会议中持续 steer(方向盘式引导)... 支持: ... / 本质:**方向盘式引导**,不是『批改已完成的成果』;VP 在过程中持续 steer,投屏/外发是 VP 想看/想发的时刻,不是『完成』标志" |
| 3 | §十 闭环 + §六 核心机制 | "Command Center控制 → 人类确认与投屏" / "VP 主动调取/调整/外发(1-3min 软目标)" | "VP 持续 steer(任何时候) → VP 任何时候投屏/外发(无『完成』前提)" / "**VP 在过程中持续 steer**(改/跳/加/换/参考,任何时候给出方向性输入,AI 实时整合,无『已完成』概念)" |
