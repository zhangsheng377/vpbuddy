本地优先的
会议 AI 系统

VPBuddy 捕获系统音频,自动转写、生成 6 种文档、构建跨会议知识库。
完全运行在 VP 桌面客户端,数据不上传云端。

5 分钟上手 → 查看源码

核心能力

从系统音频到跨会议知识库,全自动本地处理。

🎙️

实时转写

funasr paraformer-zh + fsmn-vad + cam++。中文识别率 > 90%,本地 GPU 加速,RTF < 0.05。

📋

结构化累积

REQ / GOAL / FEAT / RISK / QUE 5 类事实自动分类,跨会议持续累积演化。

📄

6 种文档

需求 / 架构 / 任务 / API / 风险 / 演示。LLM + fallback 兜底,保证一定写盘。

🧠

跨会议 KB

sqlite-vec + sentence-transformers,384 维向量,余弦相似度跨会议检索。

🔊

音频 loopback

PipeWire / PulseAudio / WASAPI / BlackHole 跨平台支持。无需 SDK 集成会议平台。

🌐

Web UI

端口 8765,深色主题,4 窗口(主屏/时间线/知识库/设置)。零 JS 框架依赖。

架构

从音频输入到知识检索,完整本地处理链路。

┌─────────────────────────────────────────────────────┐
│  VP 桌面客户端 (Ubuntu 24.04 / macOS 14+ / Win11)  │
├─────────────────────────────────────────────────────┤
│  Audio loopback (PipeWire / WASAPI / BlackHole)     │
│        ↓                                            │
│  ASR (funasr paraformer-zh, GPU 可选)              │
│        ↓                                            │
│  MeetingState (5 类事实累积)                       │
│        ↓                                            │
│  6 × sub_session (in-process AIAgent)              │
│  ┌────┬────┬────┬────┬────┬────┐                  │
│  │req │arch│tasks│api │risk│demo│                  │
│  └────┴────┴────┴────┴────┴────┘                  │
│        ↓                                            │
│  Knowledge Base (sqlite-vec + embedding)            │
│        ↓                                            │
│  Web UI (FastAPI + Vanilla JS, port 8765)          │
└─────────────────────────────────────────────────────┘

5 分钟上手

从零到开会中用起来,只需 3 步。

1

安装

git clone https://github.com/zhangsheng377/vpbuddy.git
cd vpbuddy
pip install -e .
2

启动 UI

vpbuddy ui
# 浏览器打开 http://localhost:8765
3

后台 controller

vpbuddy controller --start
# 7×24 监听,自动生成 6 文档
