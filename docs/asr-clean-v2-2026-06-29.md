## 关键发现

### 1. AIAgent 不支持本地 ollama 模型名
- `qwen3:8b` 是 ollama 模型名, AIAgent dispatch 把它当 OpenAI 协议 model 发到 minimaxi.com
- 返回 `HTTP 400: invalid params, unknown model 'qwen3:8b' (2013)`
- **解决**: ASR 整理绕开 AIAgent, 直接 urllib 调 ollama `/api/chat`
- 6 子 session / VP Chat 仍走 AIAgent — 不改, 因为它们要 tool calling, qwen3:8b 能力不够

### 2. 已修复老 bug
- `_process_chunk_background` 的 if-asr-clean 分支改了 `meta` 但没 `_save_stream_meta()`
- 修复: 加 `_save_stream_meta(meeting_id, meta)` 在 push_event 之前

### 3. 截断保护
- `ASR_CLEAN_MAX_CHARS = 2000` 字符上限
- 超长时截断到 2000 字 + 标记 `truncated=true`
- 客户端用户看到截断提示 "[...已截断, 原始 N 段在 cleaned_windows 回查]"
- 真实数据: 21 段 65s 音频 → 860 字, 远低于上限, 未触发截断
