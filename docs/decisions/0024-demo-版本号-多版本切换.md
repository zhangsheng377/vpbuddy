# 0024. demo 版本号 + 多版本切换

- **状态**: 已接受
- **日期**: 2026-07-01
- **作者**: 张胜东 (起草: Hermes)
- **替代**: 无 (新增)
- **依赖**: 无 (与 ADR-0023 / 0025 协同)

## 背景

2026-07-01 张胜东需求: "demo 要有版本号, 还要能切换不同的版本"。

**当前状态**:
- Tauri 客户端 `<section id="panel-demo">` 只有一个 `<iframe id="demo-iframe">`, 没有版本下拉
- 服务端 demo agent (推断) 把生成结果写到 `data/docs/{meeting_id}/demo.html` (单文件, 覆盖式)
- SSE 推 `doc-update` 事件时, `kind=demo` → 客户端 iframe 刷新 src, 但**只能看当前最新**, 旧版本直接被覆盖丢了

**核心问题**:
1. 用户看不到 demo 的演变过程 (v1 → v2 → v3, 旧版被覆盖)
2. demo agent 持续迭代 (跟 6 doc 一样, 会议期间会重做) 时, 旧版应该是资产不是垃圾
3. 用户想对比"v1 跟 v3 哪里不同"时无法回溯

## 决策

### 1. demo 文件按版本号增量存储

**目录结构** (改 `data/docs/{meeting_id}/`):
```
data/docs/{meeting_id}/
├── demo_v1.html        # 旧版保留, 不删
├── demo_v2.html        # 新版本
├── demo_v3.html        # 最新
├── demo_latest.html    # 软链 → demo_v{N}.html (最新 N)
├── demo_manifest.json  # 版本清单
└── (req/arch/tasks/api/risk 单文件不变, 走 6 doc agent 的覆盖式)
```

**版本号规则**:
- v1, v2, v3, ... 整数递增, 1-based
- 每次 demo agent 跑完一轮, 检查当前最新 vN, 新版 = vN+1
- `demo_latest.html` 总是 symlink → 最新 vN
- `demo_manifest.json` 记录每版的 metadata: `version`, `created_at`, `trigger` (用户问 / 6 doc 完成 / 主动迭代), `summary` (一句话描述), `file_size`

**清理策略** (一期不删, 永久保留; v0.7+ 加 LRU 保留最近 20 版):
- 一期: 永久保留所有版本 (磁盘便宜, 几 KB ~ 几 MB / 版)
- v0.7+: 加 LRU 保留最近 N 版, 老的归档到 `data/docs/{meeting_id}/archive/demo_v{old}.html`

### 2. demo agent 输出改带版本号

**改 demo agent prompt** (在 `src/vpbuddy/sub_session_controller.py` 或专门的 `demo_agent.py`):

```python
async def run_demo_agent(meeting_id: str) -> int:
    """返回新版本号 (1, 2, 3, ...)"""
    # 1. 查当前最新 vN
    manifest = load_manifest(meeting_id)
    next_v = max([m["version"] for m in manifest], default=0) + 1
    
    # 2. 调 LLM 生成 demo HTML
    demo_html = await llm_generate(...)
    
    # 3. 写文件 (增量, 不覆盖)
    out_path = DOCS_DIR / meeting_id / f"demo_v{next_v}.html"
    out_path.write_text(demo_html, encoding="utf-8")
    
    # 4. 更新 manifest
    manifest.append({
        "version": next_v,
        "created_at": datetime.now().isoformat(),
        "trigger": "user_chat" / "docs_complete" / "auto_iterate",
        "summary": extract_first_paragraph(demo_html),  # 1 句话描述
        "file_size": out_path.stat().st_size,
        "file": f"demo_v{next_v}.html",
    })
    save_manifest(meeting_id, manifest)
    
    # 5. 更新 symlink
    latest = DOCS_DIR / meeting_id / "demo_latest.html"
    if latest.exists() or latest.is_symlink():
        latest.unlink()
    latest.symlink_to(f"demo_v{next_v}.html")
    
    # 6. 推 SSE
    push_event(meeting_id, "demo-new-version", {
        "version": next_v,
        "summary": manifest[-1]["summary"],
        "file_size": manifest[-1]["file_size"],
    })
    
    return next_v
```

**`ui/main.js` 新 `loadDemoVersions()` 函数**:

```javascript
async function loadDemoVersions() {
    const r = await fetch(`/api/meetings/${currentMeetingId}/demo/versions`);
    const data = await r.json();  // {versions: [{version, created_at, summary, file_size}, ...]}
    const sel = document.getElementById("demo-version-select");
    // 按版本倒序填 (最新在上)
    sel.innerHTML = data.versions.slice().reverse().map(v =>
        `<option value="${v.version}">v${v.version} · ${v.summary} · ${new Date(v.created_at).toLocaleString('zh-CN', {month:'2-digit',day:'2-digit',hour:'2-digit',minute:'2-digit'})}</option>`
    ).join('');
    if (data.versions.length > 0) {
        const latest = Math.max(...data.versions.map(v => v.version));
        sel.value = latest;
        loadDemoVersion(latest);
    }
}

function loadDemoVersion(version) {
    document.getElementById("demo-iframe").src = `/docs/${currentMeetingId}/demo_v${version}.html`;
    // 顺便填 info
    fetch(`/api/meetings/${currentMeetingId}/demo/versions`).then(r => r.json()).then(data => {
        const v = data.versions.find(x => x.version === version);
        if (v) {
            document.getElementById("demo-version-info").textContent =
                `大小: ${(v.file_size/1024).toFixed(1)}KB · 创建: ${new Date(v.created_at).toLocaleString('zh-CN')}`;
        }
    });
}
```

**SSE `demo-new-version` 事件监听**:

```javascript
listen("demo-new-version", (e) => {
    const v = e.payload;
    // 1. 重新拉版本列表
    loadDemoVersions();
    // 2. 切到最新
    document.getElementById("demo-version-select").value = v.version;
    loadDemoVersion(v.version);
    // 3. 顶部弹提示 "🎨 demo v{N} 已生成, 描述: {summary}"
    showToast(`🎨 Demo v${v.version} 已生成: ${v.summary}`);
});
```

## 风险与回滚

| 风险 | 缓解 |
|------|------|
| demo 不断迭代, 旧版占盘 (每版几 MB × 几十版 = 几百 MB) | 一期不删, v0.7+ 加 LRU 保留最近 20 版 |
| symlink 在 Windows 客户端可能不支持 (developer mode 没开) | Windows 用 `demo_latest.html` 真复制 (一期), v0.7+ 用 NTFS junction 或硬链 |
| demo_v{N}.html 命名冲突 (多人协作) | 加 UUID 后缀: `demo_v{N}_{uuid[:8]}.html`, manifest.file 字段是完整名 |
