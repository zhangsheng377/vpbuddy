# ADR-0007: 多平台适配器架构(Step 6)

**状态**: 实施中(MVP 阶段只列能力,大部分 API 未实现)
**日期**: 2026-06-21
**作者**: Hermes (VPBuddy 设计)
**相关**: ADR-0001(MVP 选型 — 飞书第一平台), ADR-0006(子 session 架构)

## 背景

VPBuddy MVP 选型(ADR-0001)以**飞书**为第一平台。但用户会议可能跑在多个平台:

- **飞书妙记** (字节, 妙记 API)
- **腾讯会议** (腾讯, 云录制转写)
- **钉钉智能会议** (阿里)
- **企业微信会议** (腾讯, WeCom)

需要一个统一抽象,让主 session / 子 session 在写 prompt 时**知道每个平台支持什么**,从而:
- 选 platform: 飞书 → 调 FeishuAdapter
- 拉转写: 飞书 → 调 adapter.fetch_transcript(token)
- 拉 ASR 对比: 调用 adapter.list_capabilities() 看是否支持 transcript

## 决策

**4 平台 × 统一接口** + **YAGNI 第一版只列能力**

### 架构

```python
class PlatformAdapter(ABC):
    @property
    @abstractmethod
    def meta(self) -> PlatformMeta: ...
    
    def list_capabilities(self) -> List[Capability]: ...
    def fetch_transcript(self, meeting_id) -> List[dict]: ...  # 默认 NotImplementedError
    def list_recent_meetings(self, limit=10) -> List[dict]: ...  # 默认 NotImplementedError
```

每个平台一个子类,继承后只需提供 `meta` 即可工作。`fetch_transcript` 等 API 在 MVP 阶段都默认 `NotImplementedError`,**用能力清单标注哪些实现哪些 TODO**。

## 关键设计点

### 1. YAGNI 严格遵守

- **只定义接口和 metadata, 不实现 API 调用**
- 飞书的 `minutes.fetch` 标 ✅ 是因为 Step 5 (miaoji_calibration.py) 实际有调用
- 飞书/腾讯/钉钉/企微 的 `minutes.transcript` 都标 🚧,真要做需要:
  - 飞书: `minutes/v1/minutes/{token}/transcript` 子 API(需要 transcript scope)
  - 腾讯: `POST /v1/meetings/{meeting_id}/transcripts` (需要企业 SSO)
  - 钉钉: 需要企业授权 + AI 能力包
  - 企微: 需要会议云录制 + 转写 API 权限

### 2. 数据类而非 dict

- `PlatformMeta` / `Capability` 用 `@dataclass` 不用 dict
- IDE 自动补全 + 类型检查 + 序列化简单(`asdict()`)

### 3. 抽象基类 + 显式 NotImplementedError

```python
def fetch_transcript(self, meeting_id: str) -> List[dict]:
    raise NotImplementedError(f"{self.meta.platform} fetch_transcript 暂未实现, ...")
```

**好处**:
- 调用方立即知道哪个平台不支持
- 错误信息指明去哪个文档看(YAGNI: 写文档不写代码)
- 子类可以选择性 override(飞书 override,其他继承默认)

### 4. 工厂 + 注册表

```python
_ADAPTERS = {
    "feishu": FeishuAdapter,
    "tencent": TencentAdapter,
    "dingtalk": DingTalkAdapter,
    "wecom": WeComAdapter,
}

def get_adapter(platform: str) -> PlatformAdapter:
    if platform not in _ADAPTERS:
        raise ValueError(...)
    return _ADAPTERS[platform]()
```

- 加新平台只需加一行
- 不依赖外部配置(YAGNI)

## 不做的事(明确)

- ❌ 不写 OAuth 流程代码(每个平台用 app_credentials 拿 token, 复杂度低)
- ❌ 不写 SDK 包装(直接用 urllib / httpx,YAGNI)
- ❌ 不写平台能力动态发现(全部 hardcode 在 meta 里)
- ❌ 不写 adapter 热重载(进程内单例即可)
- ❌ 不写 WebSocket 适配(企微/钉钉 Stream 模式不是 MVP 必须)
