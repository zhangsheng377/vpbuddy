# ADR-0011:HF 模型离线铁律 — 默认走本地 cache

**日期**:2026-06-23
**状态**:✅ Accepted
**作者**:张胜东 + Hermes
**关联**:ADR-0005 ModelScope / [踩坑记录 §21 HF 离线铁律](../部署/踩坑记录.md#21)

---

## Context

2026-06-23 凌晨,GPU 服务器启动 `vpbuddy ui` 后,UI 卡在 "预热 KB embedding 模型" 60 秒后 timeout:

```
ConnectTimeoutError: HTTPSConnectionPool(host='huggingface.co', port=443)
```

**根因**:
1. 国内 huggingface.co 被墙,直连会卡 10s × 5 retry = 50s timeout
2. `sub_session_controller.py:38` 设了 `HF_HUB_OFFLINE=1`,但 UI 进程**不依赖 controller**,独立启动时该 setdefault 不生效
3. controller 进程跑得好(因为它先 setdefault),UI 进程是单独的 vpbuddy entry,没设 → 卡
4. **本来** sentence-transformers 模型已下到本地 cache (`~/.cache/huggingface/hub/models--sentence-transformers--paraphrase-multilingual-MiniLM-L12-v2/`),设 `HF_HUB_OFFLINE=1` 应该直接走本地

**临时绕开**:手动 `export HF_HUB_OFFLINE=1 HF_ENDPOINT=https://hf-mirror.com` 后 nohup 启动 → 25 秒 ready

**问题**:这种"临时 export"不是工程方案,任何人(VP/运维)再启动都会踩。

## Decision

**所有 vpbuddy entry 启动时,自动 setdefault HF 离线环境变量**。三层防护:

### 第 1 层 — 代码层(任何 vpbuddy 启动都生效)

`src/vpbuddy/__init__.py` 顶部(在 import huggingface 之前):

```python
import os
os.environ.setdefault("HF_HUB_OFFLINE", "1")
os.environ.setdefault("TRANSFORMERS_OFFLINE", "1")
os.environ.setdefault("HF_ENDPOINT", "https://hf-mirror.com")
```

`src/vpbuddy/ui_server.py` 顶部同样(独立进程,不走 vpbuddy/__init__ 时也安全)。

`src/vpbuddy/sub_session_controller.py:38-39` 已有,无需改。

### 第 2 层 — 启动脚本层(运维入口)

新 `scripts/start-vpbuddy.sh`:

```bash
export HF_ENDPOINT="${HF_ENDPOINT:-https://hf-mirror.com}"
export HF_HUB_OFFLINE="${HF_HUB_OFFLINE:-1}"
export TRANSFORMERS_OFFLINE="${TRANSFORMERS_OFFLINE:-1}"
export PYANNOTE_LOCAL_DIR="${PYANNOTE_LOCAL_DIR:-$HOME/pyannote_models}"
```

### 第 3 层 — install 脚本层(机器首次部署)

`scripts/install-gpu-server.sh` 把环境变量写进 `~/.bashrc`(机器重启后仍生效,可选):

```bash
cat >> ~/.bashrc <<'EOF'

# VPBuddy HF 离线铁律 (ADR-0011)
export HF_ENDPOINT=https://hf-mirror.com
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
EOF
```

### setdefault vs hardcode

**`setdefault` 而非 `os.environ[...] =`**:
- 用户可以临时覆盖:`HF_HUB_OFFLINE=0 vpbuddy controller` 允许下载新模型
- 默认走本地 cache(快、稳、不依赖外网)

## Consequences

### ✅ 好处

1. **零配置启动** — 任何人 `bash scripts/start-vpbuddy.sh` 就能跑,不踩 timeout
2. **国内环境原生支持** — 默认 hf-mirror(国内可访问)
3. **可逆** — 临时 `HF_HUB_OFFLINE=0` 即可下新模型,不影响开发
4. **三层防护** — 代码 + 启动脚本 + bashrc,任何路径启动都安全

### ⚠️ 代价

1. **默认走本地 cache,模型过期** — 用户必须手动 `HF_HUB_OFFLINE=0 vpbuddy setup-gpu` 更新
2. **gated 模型受限** — hf-mirror 对 `pyannote/...` 等 gated 模型仍 403,需要原始 HF_TOKEN(ADR-0005)
